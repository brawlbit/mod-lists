# Rubric for trust worthiness 💯



**FULLY TRUSTED:** ✅
- good rep in the community


- no history of repo take overs


- no untrusted developers

**MOSTLY TRUSTED:** 🟨
- decent rep in the community

- untrusted developers are fine, but the mod can't be fully developed by untrusted developers

- history doesn't matter unless it was previously ratted

**UNTRUSTED:** 🟥
- mostly  un-trusted developers
- either ratted or had been ratted
- terrible history

**UNKNOWN TRUST:** 🟨🟨
- probably obfuscated so i can't check if its trusted or not

- applies mostly to paid loaders
